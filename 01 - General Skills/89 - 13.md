## Descripción

La criptografía puede ser sencilla, ¿sabes qué es ROT13?

Reto de criptografía de picoCTF 2019, creado por Alex Fulton y Daniel Tunitis.

Mensaje cifrado:

```text
npnqrzl{abg_gbb_onq_bs_n_ceboyrz}
```

## Solución

1. Identificar ROT13, un cifrado César con desplazamiento de 13 posiciones.

2. Aplicar ROT13 a todas las letras. Por ejemplo, `npnqrzl` se convierte en `academy`.

3. Automatizar la conversión con el módulo `codecs` de Python.

```python
import codecs

cifrado = "npnqrzl{abg_gbb_onq_bs_n_ceboyrz}"
print(codecs.decode(cifrado, "rot_13"))
```

Solución:

```text
academy{not_too_bad_of_a_problem}
```

## Notas adicionales

- ROT13 transforma `A ↔ N`, `B ↔ O`, `C ↔ P`, y así sucesivamente.
- Aplicar ROT13 dos veces recupera el texto original.
- Los guiones bajos y las llaves se conservan.
- El resultado se verificó con la cadena cifrada proporcionada.
