## Descripción

Descargar una imagen PNG y encontrar la bandera oculta mediante esteganografía. Reto de Forensics, dificultad media, de picoCTF 2022.

## Solución

1. Descargar `academy.flag.png`. La imagen tiene 661 × 181 píxeles y modo RGBA.

2. Extraer el bit menos significativo de cada canal RGB, recorriendo los píxeles por filas. El canal alfa se excluye en este reto.

3. Agrupar los bits de ocho en ocho, interpretando el primero como el bit más significativo de cada byte. Se utilizó Python y Pillow:

```python
import re
from PIL import Image

imagen = Image.open("academy.flag.png").convert("RGB")
bits = [valor & 1 for pixel in imagen.getdata() for valor in pixel]
datos = bytes(
    sum(bits[i + j] << (7 - j) for j in range(8))
    for i in range(0, len(bits) - 7, 8)
)
print(re.search(rb"academy\{[^}]+\}", datos).group().decode())
```

4. El texto comienza con la bandera y continúa con `$t3g0` y bytes nulos. Enviar solamente la bandera. La plataforma la acepta.

Solución:

```text
academy{7h3r3_15_n0_5p00n_7e497237}
```

La bandera fue introducida en la plataforma y aceptada con el mensaje `Correct flag!` el 17 de octubre de 2026.

## Notas adicionales

- LSB significa bit menos significativo. Cambiarlo altera muy poco el color del píxel.
- El orden de los canales y la inclusión del canal alfa afectan el resultado.
- Dependencia para reproducir el código: `python -m pip install pillow`.
