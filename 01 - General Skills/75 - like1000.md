## Solución
````
Descargamos el archivo `.tar`:

```bash
cd ~/Downloads
wget https://challenge-files.cylabacademy.net/library/0fcc092f4e3d0027bc89f6de85e2b750462dca0a96c5643e38e5825e2da1c3d2/1000.tar
````

Como el archivo estaba comprimido muchas veces dentro de otros archivos `.tar`, usamos un script en Python para extraerlos automáticamente uno tras otro:

```
python3 - <<'PY'
import tarfile
import os

current = "1000.tar"

while True:
    with tarfile.open(current) as tar:
        names = tar.getnames()
        tar.extractall()

    os.remove(current)

    next_files = [n for n in names if n.endswith(".tar")]

    if not next_files:
        print("Archivo(s) final(es):")
        for n in names:
            print(n)
        break

    current = next_files[0]
PY
```

Al terminar la extracción se obtuvo una imagen con la bandera.

## Notas adicionales
- Un archivo `.tar` puede contener otros archivos `.tar` en su interior.
- En este reto se necesitó repetir la extracción muchas veces hasta llegar al archivo final.
- El script permitió automatizar el proceso en lugar de extraer cada archivo manualmente.
