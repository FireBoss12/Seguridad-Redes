## Descripción

Se proporciona `red.png` con la descripción «RED, RED, RED, RED». Se debe encontrar la información oculta. Reto de Forensics, dificultad fácil, de picoCTF 2025.

## Solución

1. Descargar `red.png`. Es una imagen RGBA de 128 × 128 píxeles.

2. Revisar el metadato `Poem`. Las iniciales de sus ocho líneas forman `CHECKLSB`, lo que apunta a los bits menos significativos.

3. Extraer el bit menos significativo de los cuatro canales RGBA, recorriendo los píxeles por filas. A diferencia de St3g0, aquí se incluye alfa.

4. Reconstruir bytes y decodificar el primer bloque Base64. Se utilizó este procedimiento:

```python
import base64
import re
from PIL import Image

imagen = Image.open("red.png").convert("RGBA")
bits = [valor & 1 for pixel in imagen.getdata() for valor in pixel]
datos = bytes(
    sum(bits[i + j] << (7 - j) for j in range(8))
    for i in range(0, len(bits) - 7, 8)
)
codificado = re.search(rb"[A-Za-z0-9+/]+={1,2}", datos).group()
print(codificado.decode())
print(base64.b64decode(codificado).decode())
```

El bloque recuperado se repite dentro de la imagen:

```text
YWNhZGVteXtyM2RfMXNfdGgzX3VsdDFtNHQzX2N1cjNfZjByXzU0ZG4zNTVffQ==
```

5. Enviar la bandera decodificada. La plataforma confirma `Correct flag!`.

Solución:

```text
academy{r3d_1s_th3_ult1m4t3_cur3_f0r_54dn355_}
```

La bandera fue introducida en la plataforma y aceptada con el mensaje `Correct flag!` el 17 de octubre de 2026.

## Notas adicionales

- La imagen contiene dos capas: esteganografía LSB y codificación Base64.
- El acróstico del poema es una pista sobre el método de extracción.
- Los caracteres `==` cierran cada bloque Base64; se conserva el relleno completo.
- Dependencia: `python -m pip install pillow`.
